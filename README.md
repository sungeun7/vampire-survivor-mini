# Mini Survivors (브라우저 미니 게임)

Canvas로 만든 **Vampire Survivors 스타일** 미니 게임입니다. **P2P 멀티플레이(PeerJS)** 와 선택적 WebSocket 서버를 지원합니다.

## 실행 방법 (가장 간단)

1) 폴더에서 `index.html`을 더블클릭해서 브라우저로 열기

> 일부 브라우저/환경에서는 로컬 파일 실행이 제한될 수 있어요. 그럴 땐 `python -m http.server 5173` 후 `http://localhost:5173` 접속.

## 멀티플레이 (P2P — 서버 불필요)

1. 한 명이 **호스트** 선택 → 화면에 **방 코드**(예: `ms-abc12xyz`) 표시
2. 다른 사람이 **조인** 선택 → 방 코드 입력 후 연결
3. 시그널링은 PeerJS 공용 서버 사용. **npm start·설치 불필요.**

## 선택: WebSocket 서버 (같은 Wi‑Fi)

- 호스트 PC에서 `npm install` → `npm start` 후 게임에서 **호스트** 선택 시 자동으로 IP/방 코드 표시
- 참가자는 **조인** → 호스트가 알려준 **방 코드** 또는 **IP**(예: 192.168.0.5) 입력

## 조작

- **P1 이동**: WASD · **P1 대시**: Space
- **P2(2인)**: 방향키 · **P2 대시**: Enter
- **일시정지**: P · **레벨 업 선택**: 1~3 또는 클릭 · **재시작**: R

## 게임 규칙

- 적이 시간이 지날수록 많아지고 강해집니다.
- 경험치를 모으면 레벨 업 후 업그레이드 선택.
- **멀티플레이**: 플레이어 수만큼 적과 아이템이 증가합니다.
